# MentoraBot

This project was built with my team mates.

## My Role

- Integrate Discord
- Improve "Ask AI" performance

## Overview

MentoraBot is an AI-driven assistant platform designed to help users with mentoring and career advice.

## Notes

- The project includes components for Discord integration and an "Ask AI" performance-focused chat flow.
- Enables alumni interaction via Discord with private channels and common channels for group collaboration.
- Uses an SQL database backend for storing user profiles, session history, and interaction logs.
